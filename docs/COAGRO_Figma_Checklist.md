# COAGRO · Preparación para Figma o Balsamiq

La consigna exige un enlace en Figma o Balsamiq. El repositorio no incluye credenciales de esas plataformas, por lo que el archivo debe crearse con una cuenta del equipo.

## Materiales listos para importar

Wireframes de baja fidelidad: `docs/wireframes/01_login.png` a `08_dashboard.png`.

Capturas de alta fidelidad: `docs/assets/01_login.png` a `09_movil.png`.

## Pasos exactos

1. Crear un archivo nuevo llamado `COAGRO POS · Prototipo funcional`.
2. Importar los ocho wireframes y colocarlos en una página llamada `Baja fidelidad`.
3. Crear ocho frames de 1440 × 900 y uno de 390 × 844.
4. Colocar las capturas de alta fidelidad dentro de los frames.
5. Conectar Login → Apertura → POS → Cobro → Factura.
6. Conectar POS → Clientes, Productos, CxC y Cierre.
7. Conectar Clientes → Evaluación crediticia y CxC.
8. Conectar Dashboard → Periodos y Liquidación de comisiones.
9. Publicar el archivo con permisos `Cualquier persona con el enlace puede ver`.
10. Copiar el enlace público al documento final y a Moodle.

## Criterio de aceptación

El enlace debe abrir sin iniciar sesión en Figma, permitir `Presentar` y recorrer las ocho pantallas con transiciones activas. Balsamiq puede usar los mismos PNG y el conector de wireframes.
